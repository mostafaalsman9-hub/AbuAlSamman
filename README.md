# ابو السمان — تسجيل المكالمات (Android 12 → Android 16)

## التشغيل
1. افتح المجلد في Android Studio (إصدار يدعم API 36، مثل Narwhal أو أحدث) وانتظر Gradle Sync.
2. شغّله على جهاز حقيقي (المحاكي لا يدعم مكالمات حقيقية).
3. افتح التطبيق، وافق على التنبيه القانوني، ثم اضغط «تشغيل التسجيل التلقائي» ووافق على الصلاحيات.
4. أبقِ إشعار «ابو السمان» ظاهراً؛ يبدأ التسجيل مع أي مكالمة ويتوقف مع انتهائها.

## الصلاحيات
| الصلاحية | السبب |
|---|---|
| RECORD_AUDIO | التقاط الصوت |
| READ_PHONE_STATE | معرفة بداية/نهاية المكالمة |
| POST_NOTIFICATIONS | الإشعار الدائم (إلزامي) |
| FOREGROUND_SERVICE + FOREGROUND_SERVICE_MICROPHONE | التسجيل في الخلفية (إلزامي من أندرويد 14) |

## قيود أندرويد (مهم)
- منذ أندرويد 10 يمنع النظام التطبيقات العادية من استخدام مصدر VOICE_CALL، لذلك يُستخدم الميكروفون.
- لتسجيل **الطرفين**: شغّل **مكبّر الصوت** أثناء المكالمة. بدونه سيُسجَّل صوتك أنت غالباً.
- بعض الأجهزة قد تُسكِت الميكروفون أثناء المكالمات الخلوية؛ اختبر على جهازك.
- من أندرويد 14+ لا يمكن بدء خدمة الميكروفون من الخلفية أو عند الإقلاع، لذا يجب فتح التطبيق وتشغيل الحماية يدوياً بعد إعادة التشغيل.
- التسجيلات في: Android/data/com.abualsamman.recorder/files/recordings

## قانونياً
سجّل فقط بموافقة الطرف الآخر وبما يتوافق مع قوانين بلدك.
